# TESTE CHAT

Landing page premium construída com React + Vite, com foco em visual moderno, responsividade, acessibilidade e organização limpa do código.

## Tecnologias

- React 18
- Vite
- CSS moderno com glassmorphism, gradientes e blur
- HTML semântico

## Como executar

```bash
npm install
npm run dev
```

Para build de produção:

```bash
npm run build
npm run preview
```

## Como publicar

O projeto está pronto para deploy em Vercel ou outro host compatível com Vite. Basta conectar o repositório e publicar a branch principal.
